# Slider updates

The update feed for Slider, a Mac app. Slider checks
[appcast.xml](https://jamdoran.github.io/slider-updates/appcast.xml) once a day and offers new builds itself.

To install Slider for the first time, download **Slider.dmg** from the
[latest release](https://github.com/jamdoran/slider-updates/releases/latest/download/Slider.dmg), open it and drag
Slider to Applications. It needs macOS 26 or later.
